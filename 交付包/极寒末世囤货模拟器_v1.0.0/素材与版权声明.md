# 素材与版权声明

## 一、素材来源

本作全部美术来自**哈士喵自有素材体系**，就地取用、未引入第三方图库：

| 类别 | 张数 | 来源与处理 |
|---|---:|---|
| 透明角色层 | 6 | 哈士喵纸娃娃规格的角色稿；绿幕泛洪去背成 RGBA 透明层，含失温 / 夜版 / 暖装 / 惊恐四态差分 |
| 三幕幕间插画 | 3 | 场景稿按角色包围盒重裁，叠 ACT 水印 |
| 事件卡插画 | 9 | 同一角色锚点生成，去平台水印后压 WebP |
| 物资卡专图 | 7 | 7 类物资各一张，采购清单与门缝交易共用 |
| 结局插画 | 11 | 11 个结局各一张统一档案封面 |
| 主页 Hero | 1 | 提亮后作封面底图 |

合计 **37 张，全部 base64 内嵌**在单个 HTML 中，解码合计 380.3 KiB / 内嵌 508.0 KiB。逐张格式、尺寸、字节数见 `docs/体积校验报告.md` 的图片资源账单。

角色设定、纸娃娃 11 层骨架与八向帧规格参照《冒险岛》纸娃娃 4.0 的**交互逻辑**，只复刻操作方式，素材全部自有。
