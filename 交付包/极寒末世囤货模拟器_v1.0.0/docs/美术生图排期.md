### R4 详细（最后一轮）

7 张物资卡专图（粮 / 水 / 燃料 / 睡袋 / 药 / 收音机 / 工具），220×165 / WebP q50 → 28.1 KiB，采购清单与门缝交易共用；事件卡仍用 R1 的 9 张，两套彻底分开。

**顺带把用户提的两件事一起做了：**
- **「过程中为啥不能买卖」**：原设计把「钱」只当采购期的限时预算，封门后现金就成死数 —— 确实不合理。补了 `🪙 门缝交易`：封门后每天可开一次，7 种物资都能买 / 卖。买价 = 原价 ×(1+天数×3%)×天气系数（冷冬 1.00 / 严寒 1.25 / 极寒 1.60 / 白毛风 2.10），卖出按原价四折；每天最多 3 件，白毛风焊死门只限 2 件。买到的功能件（睡袋 / 药 / 收音机 / 工具）同步进事件判定与结局判定，不是摆设。
- **「留钱也算有点念想」**：花 ¥88 可留一封没寄出的信；结算页新增「账本最后一页」按余额分档给一句人话（≥500「留着吧，万一有人来呢」/ 小额「像是给谁留着」/ 花光「只记着今天烧了多少煤」），分享文案与 750×1000 成绩卡都带余额行；`END_MONEY` 结局判定不动，只把结语从纯嘲讽改成「哈士喵把那叠钞票又夹回账本最后一页」。

**实测真的能续命**：同参数（冷冬 / ¥6000 / 3 天 / 睡袋×1 + 粮 12 水 12 煤 6）两局对照，不交易 **5 天**，每天门缝买满粮水煤 **9 天**，**+4 天**；念想行、分支统计、分享余额、存档 `left/keep` 全部生效。
