## 三、玩法

开局定**倒计时 / 四档天气 / 资金**，在「钱 + 出门工时」双限下采购 7 类物资（粮 / 水 / 燃料 / 睡袋 / 药 / 收音机 / 工具）。封门后逐日扣消耗，3 幕结构、每 7 天营地会议、25 个事件（含跨天连锁），由纯函数 `resolveEnding(ctx)` 按优先级判定 **11 种结局**。

核心是**木桶短板**：堆得最多的那件，从来不是决定天数的那件。

已实现的系统：

- **门缝交易**：封门后每天可买卖，买价随天数与天气上涨；白毛风档递取次数更紧
- **最后窗口**：断供前一次性补救，三个选项都要付代价；复盘写明是否抓住
- **结算复盘**：首个失衡日、断供前 3 天轨迹、天气倍率、下次改一处的建议
- **采购预测**：按当前天气算粮 / 水 / 煤 / 身体预计天数并标最短板
- **首局引导**：首次进入预设固定档，三处两行提示，结算后解锁自由设定
- **每日挑战**：`HSMS1-` 离线挑战码，同种子锁天气 / 预算 / 事件序列
- **结局图鉴**：11 格带达成线索，未解锁不剧透；跨局保留
- **排行榜**：本机榜 + 好友榜（成绩码导入，带校验位防手滑）
- **分享**：文案、`HSM1-` 成绩码、750×1000 Canvas 成绩卡
- **断点续玩**：逐日存档，刷新可接着上次封门那天

## 四、校验方式

```bash
sha256sum -c SHA256SUMS                          # 校验包内每个文件的完整性
python3 tools/check_size.py 极寒末世囤货模拟器_完整版.html
CHROME_PATH=/path/to/chrome node tools/browser_check.js
```

- `check_size.py` 会在**当前目录**刷新 `体积校验报告.md` 和 `size_history.json`，复核时建议先复制一份到临时目录再跑
- 包内 `browser_check.js` 已改成相对包根定位产物、截图输出到 `_shots/`；`CHROME_PATH` 可省略（此时用 Playwright 自带浏览器）。需本机 Node.js + Playwright
- `tools/` 内脚本用于复现校验，**重建 HTML 还需本地素材目录**（未随上架包分发，见版权声明）。本包已附构建后的校验结果，无需重建即可复核
